# Prompts

Four ready-made prompts. Fill the short brief at the top of each file and paste the whole file into your
coding agent. In Claude Code they are also skills: `/new-view`, `/new-module`, `/refactor-to-ds`, `/polish`.

| Prompt | Use it when |
|---|---|
| [new-view.md](new-view.md) | a new screen (list, detail, dashboard) inside an existing module |
| [new-module.md](new-module.md) | a new entity with its table, access rows, list, detail and creation |
| [refactor-to-ds.md](refactor-to-ds.md) | a screen built outside the system must come onto it |
| [polish.md](polish.md) | a screen works and must be finished |

They are short on purpose: the rules live in `docs/RULES.md`, the components in `docs/COMPONENTS.md`.
